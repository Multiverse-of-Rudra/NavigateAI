# 🚀 NavigateAI

**From Confusion to Contribution.**

NavigateAI is an AI-powered open-source repository navigator that helps developers understand GitHub repositories faster, learn codebases efficiently, and start contributing with confidence.

Instead of spending hours reading documentation and exploring folders, developers can simply paste a GitHub repository URL and get AI-generated insights, learning paths, architecture explanations, and contribution guidance.

## 🌟 Why NavigateAI?

Open-source repositories can be overwhelming for new contributors.

Common challenges include:

- Complex project structures
- Large codebases
- Unclear starting points
- Insufficient onboarding
- Time-consuming learning curves

NavigateAI solves these problems by transforming repositories into structured, beginner-friendly experiences.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Multiverse-of-Rudra/NavigateAI.git
cd NavigateAI
npm install
```

Create a `.env.local` file:

```env
GITHUB_TOKEN=your_github_token
GOOGLE_API_KEY=your_google_api_key
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
